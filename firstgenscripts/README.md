FIRST GEN SCRIPTS- Samples

The first generation operations that became Scattered Vision were a series of scripts. Not all of those scripts are supplied with this project.

Three remaining scripts have been included with the project for utility usage as their function is outside of the functions in Scattered Vision.

deletenofaces.py- scans a directory and deletes files wherein face_recognition detects no faces.

facialcompare.py- Identifies matches of faces from a specified file with a specified source directory

findfacesandcopyfiles.py - identifies files with encodeable faces from a specified directory and copies those files to a designated directory
